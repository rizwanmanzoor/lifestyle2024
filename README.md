# LifestyleCo - Physiotherapy & Patient Rehabilitation Platform

A specialized web application designed for physiotherapy practices and patient care management, featuring localized Urdu interface support, rehabilitation exercise tracking, patient education, and custom diet plans.

🔗 **Live Application:** [lifestyleco.developersouls.com](https://lifestyleco.developersouls.com/)

---

## 🚀 Overview

LifestyleCo provides structured care plans for physiotherapy patients. The interface simplifies patient compliance by breaking down rehabilitation schedules, daily exercise instructions, and nutritional guidelines into accessible, day-by-day views.

---

## 🛠️ Tech Stack & Architecture

- **Frontend Core:** React.js / TypeScript
- **Localization:** RTL (Right-To-Left) layout & Nastaliq typography support for Urdu UI
- **Styling & UI:** Custom responsive styling with dynamic accordion & collapsible menu components
- **Deployment & Hosting:** Deployed on custom domain via Hostinger / DeveloperSouls infrastructure

---

## ✨ Key Features

- **Localized Urdu Interface (RTL):** Full right-to-left UI tailored for native Urdu-speaking patients.
- **Interactive Care Plan Categorization:**
  - **ورزش (Exercise Routines):** Muscle stretching, joint mobility, and timed physical exercises.
  - **تعليم (Patient Education):** Pain prevention, balance control guidelines, and recovery advice.
  - **غذائيت (Dietary Chart):** Allowed foods and dietary restriction breakdowns.
- **Dynamic Daily Schedules:** Filter routines by specific days and daily time slots (Morning, Afternoon, Evening).
- **Responsive Mobile Layout:** Optimized for seamless viewing on smartphones and tablets for ease of use by patients.
